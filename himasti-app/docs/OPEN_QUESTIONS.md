# Open Questions

Codex harus menanyakan hal berikut setelah membaca proyek dan dokumentasi. Jangan menanyakan pertanyaan yang jawabannya sudah terlihat jelas dari kode.

## Stack dan Kondisi Repository

1. Framework backend dan frontend apa yang sudah digunakan?
2. Apakah proyek sudah memiliki autentikasi admin?
3. Apakah database migration dan model awal sudah tersedia?
4. Apakah UI landing page atau admin dashboard sudah ada?
5. Sistem penyimpanan gambar saat ini menggunakan local storage, public storage, atau layanan cloud?

## Scope Implementasi

6. Apakah tahap pertama hanya membuat database dan backend CRUD, atau sekaligus UI publik dan admin?
7. Apakah semua admin memiliki akses penuh, atau role berbeda harus langsung diterapkan?
8. Apakah BPH dan MPH memang tidak memiliki program kerja?
9. Apakah dokumentasi wajib maksimal lima gambar atau boleh tidak terbatas?
10. Apakah event memiliki halaman detail dan link pendaftaran?

## Konten dan Tampilan

11. Berapa jumlah berita, event, dokumentasi, dan Instagram post yang ditampilkan di landing page?
12. Apakah desain landing page sudah tersedia?
13. Apakah profil himpunan, visi, misi, dan sambutan ketua harus dapat diedit admin?
14. Apakah Instagram post diinput manual atau diambil melalui API Instagram?
15. Apakah layanan hanya berupa link eksternal?

## Teknis

16. Database apa yang digunakan?
17. Apakah soft delete diperlukan untuk semua konten?
18. Apakah rich text editor dibutuhkan untuk berita?
19. Apakah gambar perlu dikompres otomatis?
20. Apakah diperlukan activity log admin?

Setelah bertanya, Codex harus menunggu jawaban sebelum melakukan implementasi besar.
